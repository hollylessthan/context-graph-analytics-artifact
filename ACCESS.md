# Public reproducibility record

The two evidence ZIP archives are permanent inputs when included in a tagged GitHub release or Zenodo record. Their contents are not dependent on GitHub Actions artifact retention. The old Actions URLs are historical provenance only and may expire.

The original research repository may not be publicly readable for all reviewers; this artifact therefore contains the evidence required for its offline checks. Full re-execution of model inference and original SQL evaluation is outside scope.

Checks: `scripts/check_export.py`, `scripts/check_additional_claims.py`, `scripts/reproduce_stage.py`, and `scripts/reproduce_paired.py`.
